---
title: Run command
description: Run a named script from the root pubspec.yaml.
---

Run a [script](/configuration/scripts) by name defined in the workspace
root `pubspec.yaml` config file.

```bash
melos run SCRIPT_NAME
```

You can also run a script directly as `melos SCRIPT_NAME`, without `run`:

```bash
melos SCRIPT_NAME
```

<Info>Supports all [Melos filtering](/filters) flags.</Info>

Pass package filter options to override or further restrict the filters
defined in the script configuration. For example, this command runs a script
only on packages that match a specific scope:

```bash
melos run test --scope="my_package*"
```

## --no-select

Skips the prompt to select a package (if defined in the script configuration).
Melos still applies filters defined in the script's `packageFilters` options.

```bash
melos run SCRIPT_NAME --no-select
```

To skip the prompt for every run, set
[`command/run/noSelect`](/configuration/overview#noselect) in the workspace
configuration.

## --run-unchanged

Runs scripts that specify [`exec/sources`](/configuration/scripts#sources) in
every package, even in the packages in which the sources did not change.

```bash
melos run SCRIPT_NAME --run-unchanged
```

## --ignore-sources

Ignores the `exec/sources` of scripts, so that they run in every package
without calculating or storing checksums. For more information, see
[`melos exec --ignore-sources`](/reference/commands/exec#--ignore-sources).

```bash
melos run SCRIPT_NAME --ignore-sources
```

## --list

Displays all scripts defined in the Melos workspace.

```bash
melos run --list
```

Use `--json` to output the list in JSON format.

```bash
melos run --list --json
```

### --include-private

Using `--include-private` ignores the `private` configuration on scripts.
Private scripts appear in prompts and listings, and you can run them directly.

```bash
melos run --list --include-private
```

### --group (-g)

Filters scripts to include only those that belong to the specified group.

```bash
melos run --group GROUP
```
